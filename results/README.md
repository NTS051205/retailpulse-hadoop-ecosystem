# Results and demo evidence

This directory is intentionally empty of analytical results. The repository build does not execute the pipeline and does not invent output values.

After you run and validate the project manually, you can save coursework evidence here, for example:

- SQL Server source row counts;
- screenshots of the six HDFS raw directories;
- the processed HDFS row count and a small, non-sensitive sample;
- Hive table descriptions and row counts;
- output from the KPI queries;
- screenshots used in the live demo or final report.

Use descriptive names such as `01_sql_source_counts.png` or `10_top_sellers.txt`. Review files before committing them: do not include passwords, connection strings containing secrets, full source datasets, or unnecessarily large outputs.
